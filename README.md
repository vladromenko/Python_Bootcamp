# Python Bootcamp

Этот репозиторий содержит учебные задания по Python, выполненные в рамках bootcamp.  
Задания идут от простых алгоритмических задач к более крупным проектам с архитектурой, слоями приложения, web-интерфейсом, хранением данных и асинхронной обработкой.

## Что есть в bootcamp

В bootcamp входят несколько блоков:

1. базовые алгоритмические задачи;
2. задачи на работу с процессами и асинхронностью;
3. консольная roguelike-игра;
4. backend-приложение для игры в крестики-нолики.

## Блок 1. Базовые алгоритмические задачи

В этом блоке собраны небольшие задачи для тренировки базового Python, циклов, условий, списков, матриц, строк, чисел и простых алгоритмов.

Здесь нужно реализовать:

- вычисление скалярного произведения двух векторов;
- проверку числа на палиндром;
- обработку матрицы с фигурами;
- построение треугольника Паскаля;
- преобразование строки в вещественное число без использования `float()`;
- объединение отсортированных списков фильмов;
- поиск максимального количества монет для робота на поле;
- подсчет количества различных чисел;
- вычисление производной многочлена в точке;
- подбор двух аппаратов одного года с минимальной общей стоимостью.

Этот блок нужен для отработки базовой логики программирования и уверенной работы с простыми структурами данных.

## Блок 2. Процессы и асинхронность

В этом блоке рассматриваются более сложные задачи, где программа должна выполнять несколько действий одновременно.

### Экзамен

Нужно реализовать программу, которая моделирует сдачу экзамена.  
Студенты стоят в общей очереди, а несколько экзаменаторов одновременно принимают экзамен. Каждый экзаменатор работает в отдельном процессе.

Программа читает данные из файлов:

- `examiners.txt`;
- `students.txt`;
- `questions.txt`.

Во время работы программа обновляет состояние экзамена в консоли, показывает статусы студентов, работу экзаменаторов, очередь и прошедшее время. После завершения выводятся итоговые результаты.

### Скачивание изображений

Нужно реализовать программу, которая принимает от пользователя ссылки на изображения и скачивает их асинхронно.

Пользователь вводит папку для сохранения, затем вводит ссылки. Каждая ссылка сразу отправляется на загрузку. После пустой строки программа ждет завершения всех загрузок и выводит таблицу со статусами `Успех` или `Ошибка`.

Этот блок нужен для практики многопроцессности, асинхронного программирования, обработки ошибок и работы с вводом пользователя.

## Блок 3. Rogue-like игра

В этом блоке нужно разработать консольную roguelike-игру на Python по мотивам классической Rogue 1980 года.

Игра работает в терминале через библиотеку `curses`. Игрок исследует случайно сгенерированные подземелья, проходит уровни, сражается с противниками, собирает предметы и сокровища.

Проект должен быть разделен на слои:

- `domain` — игровая логика;
- `presentation` — отображение и управление через `curses`;
- `datalayer` — сохранение и загрузка данных.

В игре нужно реализовать:

- 21 уровень подземелья;
- генерацию комнат и коридоров;
- персонажа с характеристиками;
- противников разных типов;
- предметы и рюкзак;
- пошаговую систему боя;
- туман войны;
- сохранение прогресса в `json`;
- таблицу статистики и рекордов.

Дополнительно можно реализовать двери и ключи, динамический баланс сложности, мимика и 3D-режим отображения.

Этот блок нужен для практики архитектуры, проектирования игровых сущностей, разделения слоев, генерации карты, работы с состоянием игры и сохранениями.

## Блок 4. Backend для крестиков-ноликов

В этом блоке нужно разработать backend-приложение для игры в крестики-нолики.

Проект должен быть разделен на слои:

- `web` — HTTP-запросы и ответы;
- `domain` — бизнес-логика игры;
- `datasource` — хранение текущих игр;
- `di` — настройка зависимостей.

В приложении нужно реализовать:

- модель игрового поля;
- модель текущей игры с UUID;
- проверку корректности ходов;
- проверку окончания игры;
- ход компьютера через алгоритм Минимакс;
- хранение нескольких игр одновременно;
- Flask-контроллер `POST /game/{UUID}`;
- мапперы между слоями;
- контейнер зависимостей.

Этот блок нужен для практики backend-разработки, Flask, архитектуры приложения, dependency injection, хранения данных и реализации игровой логики на сервере.
